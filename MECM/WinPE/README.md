# WinPE

Helpers for operating system deployment (OSD) task sequences.

## Contents

| Folder | Purpose |
|--------|---------|
| [`OSD-ComputerSetup/`](OSD-ComputerSetup/) | WinPE prestart command that asks the imaging technician for a computer role (OU) and a host name before the task sequence runs. Also holds the pre-WinPE step that keeps the name and OU of a computer in a refresh. See its README. |
